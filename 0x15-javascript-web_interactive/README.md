# 0x15. JavaScript - Web interactive

## Description
This project covers DOM manipulation and event handling using vanilla JavaScript.

## Files
- `0-script.js`: Updates the text color of the `<header>` element to red (`#FF0000`).
- `1-script.js`: Updates the text color of every `<p>` element to blue (`#0000FF`).
- `2-script.js`: Updates header text color to red on click of `DIV#red_header`.
- `3-script.js`: Adds class `red` to header on click of `DIV#red_header`.
- `4-script.js`: Toggles class `red`/`green` on header when clicking `DIV#toggle_header`.
- `5-script.js`: Adds `<li>Item</li>` to `UL.my_list` when clicking `DIV#add_item`.
- `6-script.js`: Changes header text content to `New Header!!!` when clicking `DIV#update_header`.

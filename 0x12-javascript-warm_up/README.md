# 0x12. JavaScript - Warm up

## Description
This project covers basic JavaScript concepts running on Node.js, including script execution, argument parsing, recursive functions, object manipulation, function exports, and higher-order functions.

## Files & Tasks

* **`9-add.js`**: Script that prints the addition of 2 integers using a defined `add(a, b)` function.
* **`10-factorial.js`**: Script that recursively computes and prints the factorial of a given integer.
* **`11-second_biggest.js`**: Script that finds and prints the second largest integer in the list of arguments.
* **`12-object.js`**: Script updating an object's `value` property from `12` to `89`.
* **`13-add.js`**: Exported `add` function accessible outside its module file.
* **`100-let_me_const.js`**: Modifies the global variable `myVar` to `333`.
* **`101-call_me_moby.js`**: Exported function `callMeMoby(x, theFunction)` that executes a function `x` times.
* **`102-add_me_maybe.js`**: Exported function `addMeMaybe(number, theFunction)` that increments a number and calls a function.
* **`103-object_fct.js`**: Script updating an object by adding an `incr` method that increments its `value` property.

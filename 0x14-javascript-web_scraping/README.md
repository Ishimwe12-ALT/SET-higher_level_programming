# 0x14. JavaScript - Web scraping

## Description
This project focuses on manipulating files using Node.js filesystem modules (`fs`) and fetching data from third-party APIs using the `request` library.

## Tasks
- **0-readme.js**: Read and print file contents.
- **1-writeme.js**: Write content to a file.
- **2-statuscode.js**: Display response status code of a GET request.
- **3-starwars_title.js**: Fetch Star Wars movie title by ID.
- **4-starwars_count.js**: Count movies featuring Wedge Antilles (character ID 18).
- **5-request_store.js**: Download webpage content and save to a file.
- **6-completed_tasks.js**: Compute completed tasks grouped by user ID.

# 0x13. JavaScript - Objects, Scopes and Closures

## Description
This project covers JavaScript Object-Oriented Programming (OOP) concepts, including ES6 classes, constructors, instance methods, inheritance using `extends` and `super`, and variable scope/closures.

## Tasks
* **0-rectangle.js**: Empty class `Rectangle`.
* **1-rectangle.js**: Class `Rectangle` with `width` and `height` attributes.
* **2-rectangle.js**: Class `Rectangle` that validates `w` and `h` are positive integers.
* **3-rectangle.js**: Adds `print()` method using character `X`.
* **4-rectangle.js**: Adds `rotate()` and `double()` methods.
* **5-square.js**: Class `Square` that inherits from `Rectangle`.
* **6-square.js**: Class `Square` with custom `charPrint(c)` method.

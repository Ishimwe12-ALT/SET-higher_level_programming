# JavaScript - Objects, Scopes and Closures Part 2

This directory contains tasks focused on JavaScript closures, function scopes, array manipulation, and base conversion.

## Tasks Overview

| File | Description |
| --- | --- |
| `7-occurrences.js` | Function that returns the number of occurrences of an element in a list. |
| `8-esrever.js` | Function that returns the reversed version of a list without using built-in `reverse`. |
| `9-logme.js` | Function that prints the number of arguments already printed and the new argument value. |
| `10-converter.js` | Function that converts a number from base 10 to another base without declaring new variables. |
